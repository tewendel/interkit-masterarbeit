# Interkit documentation

Welcome to the interkit docs!

### Structure of the docs

There are two main areas
- **Guides** – Learn how to do things
- **[Reference](/reference)** – Look up technical details

### Getting started

If you're just getting started, we recommend you read through the overview guides, such as [What is interkit?](/guides/overview/what-is-interkit) for different user groups like project managers, developers, artists and designers. 

Then have a look at the [quick start guides](/guides/quick-start/elements) or dive into the [tutorial](/guides/tutorial/intro).

For instructions on setting up your own interkit server, [click here](/guides/howto/server_setup).
