# Styling & Theming Demo

Note: Toggle the theme with **use theme** in the preview settings

### Techniques demonstrated

- Channging the interkit style variable for general text style (in the `Styling` section)
- Using `global.css`
    - to load a font from google fonts
    - to load a font from a local asset
    - use of custom css variables
    - overwrite an interkit style variable
    - define a style for the Card header
    - prefixing css selectors with `#Theming` to ensure specificy
    - load a custom local asset from css as background image
    - implement a larger change in appearence using animations
- Using `global.js`
    - to implement a ticker animation
    - to modify html event when navigation occured
- replacing icons with custom icon files
- Using the Theming component to modify just a specific part of the css

### Files to look at

- `static/theme/global.css`
- `static/theme/global.js`
- `svg` files in `static/theme/icons/`
