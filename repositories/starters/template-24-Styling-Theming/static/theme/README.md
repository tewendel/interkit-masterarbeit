# Theme Starter / Example

This theme demonstrates the possibilities of theming and can be used as a starter for your own theme:

- overwrite interkit CSS variables from Base Design
- change the style of a individual component
- scoping CSS with `#Theming``
- import another CSS file
- import fonts
- use theme variables
- add background images
- use javascript and CSS to create animations
- use custom icons
